# Decisiones de arquitectura (ADR)

Un ADR explica **qué se decidió, por qué, qué alternativas se descartaron y qué
consecuencias tiene**. Sirve para no repetir un debate que ya se tuvo.

No hay uno por cada decisión: solo para las que serían difíciles de entender
dentro de seis meses.

| ADR                                       | Decisión                                      |
| ----------------------------------------- | --------------------------------------------- |
| [ADR-001](ADR-001-playwright.md)          | Playwright para toda la automatización        |
| [ADR-002](ADR-002-dato-ausente.md)        | Un dato ausente se representa por su ausencia |
| [ADR-003](ADR-003-sin-modulos-nativos.md) | Ninguna dependencia que compile código nativo |

Las decisiones de producto, más cortas, están en la tabla de
[SYSTEM_VISION.md](../../SYSTEM_VISION.md) (D1–D16).
